# EXCLUSIVE AUTO TRADE

Платформа за внос на автомобили от Южна Корея (фиксирана цена и търгове): каталог със сървърно филтриране, детайлни страници,
калкулатор за внос, VIN проверка, проследяване на доставки, потребителски профил и админ панел.

**Стек:** Next.js 16 (App Router, TypeScript) · Tailwind CSS 4 · shadcn/ui-стил компоненти (Radix, cva, lucide) · Motion ·
PostgreSQL + Prisma 7 · jose (JWT сесии) + bcrypt · zod валидация.

## Стартиране

```bash
cp .env.example .env          # попълнете DATABASE_URL и AUTH_SECRET (openssl rand -base64 48)
npm install
npm run db:push               # създава таблиците
npm run db:seed               # демо данни (ВСИЧКО е измислено и маркирано като демо)
npm run dev                   # http://localhost:3000
```

Демо акаунти (парола `Demo!12345` — сменете или изтрийте ги преди публикуване):
`admin@exclusive-auto.example` · `manager@exclusive-auto.example` · `client@exclusive-auto.example`.
Демо проследяване: поръчка `EAT-2026-0001` + последните 6 символа от VIN на поръчката (виж в админ → поръчки).

Изображение в началото: сложете собствена снимка в `public/images/hero.jpg` (препоръчително ≥2000 px). Без нея се показва демо визуализация.

## Структура

| Път | Съдържание |
|---|---|
| `src/app` | страници (каталог, детайл, калкулатор, `/vin-check`, `/tracking`, `/compare`, `/find-my-car`, `/account/*`, `/admin/*`, съдържание, legal) |
| `src/lib/pricing.ts` | **калкулаторът**: митническа стойност (CIF) → мито → ДДС върху (CIF + мито + пристанищни такси) |
| `src/lib/providers` | адаптери за Encar, K Car, Autowini към общ модел `NormalizedVehicle` |
| `src/lib/actions` | сървърни действия (auth, запитвания, потребител, админ) с zod валидация и проверка на роли |
| `prisma/schema.prisma` | модел на данните; `prisma/seed.ts` — демо данни |
| `legacy-static/` | предишният статичен сайт (за справка) |

## Роли и достъп
- **ADMIN** — всичко, вкл. потребители, роли, цени/мито, контакти.
- **MANAGER** — автомобили, запитвания и оферти, поръчки, блог, FAQ, отзиви и доставки.
- **CUSTOMER** — собствен профил, любими, запитвания, оферти, поръчки, документи.
`src/proxy.ts` пренасочва нелогнати към вход; реалната проверка на сесията и ролята (от базата) е във всяка страница/действие.

## Данни от доставчици
Адаптерите четат **лицензиран JSON фийд/API** от `*_API_URL` и `*_API_KEY` и не правят scraping. Без ключ доставчикът се пропуска и
остават демо данните. Форматът на съпоставяне е в `src/lib/providers/adapters.ts` и се коригира според документацията на реалния
доставчик. Синхронизация: бутон в админ → Автомобили или `npm run sync:providers`. Известия за запазени търсения: `GET /api/cron/saved-searches`
с `Authorization: Bearer $CRON_SECRET` (по cron).

VIN история от външен доставчик: `VIN_HISTORY_API_URL/KEY` (очакван отговор в `src/lib/vin-provider.ts`). Без него `/vin-check` работи в
демонстрационен режим само със записи от собствената база — не се генерира история.

### Carapis (автоматични обяви от Encar и др.)
Адаптерът `src/lib/providers/carapis.ts` чете `GET https://api.carapis.com/v2/listings` (Bearer ключ). Променливи: `CARAPIS_API_KEY`,
`CARAPIS_SOURCES` (напр. `encar`), `CARAPIS_MAX_LISTINGS`, `CARAPIS_QUERY` (филтри), `SYNC_PUBLISH=false` (новите обяви са скрити за преглед).
Синхронизация: бутон в админ → Автомобили или автоматично с `GET /api/cron/sync-providers` + `Authorization: Bearer $CRON_SECRET` (cron).
Изчезналите от пълния списък обяви се архивират. Преди търговска употреба проверете условията на Carapis и на платформите.

## Калкулатор и митнически правила
Всички ставки, курсове, такси и комисиони се редактират в админ → **Цени и мито** (таблица `Setting`). Стойностите по подразбиране са
**примерни** и трябва да се съгласуват с митнически брокер (ТАРИК, произход по ССТ ЕС–Корея, актуални такси на платформите).
Резултатът винаги е означен като ориентировъчна оценка. Цените на обявите се пазят и в EUR (`priceEur`) за филтриране/сортиране —
след промяна на курсовете използвайте „Преизчисли цените“.

## Сигурност
Хеширани пароли (bcrypt), httpOnly JWT cookie, zod валидация на сървъра, rate limiting (in-memory — за няколко инстанса го заменете с Redis),
honeypot и GDPR съгласие във формите, проверка на файлове по „магически байтове“, лични документи само през оторизиран endpoint,
защитни HTTP хедъри, `robots`/`sitemap`, JSON-LD (Car, FAQ, Article).

## Публикуване
Нужен е Node хост с PostgreSQL (Vercel/Render/Railway/VPS) — **не** статичен хостинг като ръчния Netlify drop.
Качените файлове се пазят в `UPLOAD_DIR` (по подразбиране `./uploads`); на хостинг без траен диск използвайте обектно хранилище.
Legal страниците са шаблони — допълнете данните на дружеството и ги прегледайте с юрист.
